# GA4 BigQuery SQL – Beginner Portfolio Project

## 📌 Project Overview
This project analyzes Google Analytics 4 (GA4) ecommerce sample data using BigQuery SQL.
The objective is to understand website traffic, user behavior, page performance, and conversions.

## 📊 Dataset
- GA4 Obfuscated Sample Ecommerce Dataset
- Source: BigQuery Public Dataset

## 🛠 Tools Used
- Google BigQuery
- SQL
- GA4 data model

## 🔍 Analysis Performed
- Total users and total events
- Daily traffic trends
- Top-performing pages
- Conversion analysis (purchase events)
- Traffic source and medium performance

## 📈 Key Insights
- A small number of pages generate the majority of page views
- Conversion rates are significantly lower compared to total traffic
- Certain traffic sources drive higher-quality users who are more likely to convert

## 🧠 Skills Demonstrated
- Writing clean SQL queries
- Working with GA4 BigQuery schema
- Event-level data analysis
- Business-focused analytics thinking
